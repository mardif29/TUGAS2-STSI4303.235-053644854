## 📱 Deskripsi Proyek

Proyek ini merupakan aplikasi mobile (berbasis framework Ionic / Vue.js / Flutter / React Native) yang menyajikan informasi prakiraan cuaca secara real-time melalui integrasi REST API.

### Fitur Utama:
- 🌤️ **Menampilkan Prakiraan Cuaca:** Menyajikan informasi cuaca terkini berdasarkan lokasi tertentu.
- 📱 **Responsif & Mobile-Friendly:** Didesain agar nyaman digunakan di perangkat seluler.
- 🔗 **Integrasi REST API:** Mengambil data kondisi cuaca (suhu, kelembapan, kondisi langit) secara langsung dari penyedia API cuaca.

## 🚀 Cara Menjalankan Proyek

### 1. Prerequisites (Prasyarat)
Pastikan Anda sudah menginstal:
- [Node.js](https://nodejs.org/) (Versi LTS)
- Package Manager: `npm` atau `yarn`

### 2. Kloning Repositori
```bash
git clone https://github.com/mardif29/TUGAS2-STSI4303.235-053644854.git
cd TUGAS2-STSI4303.235-053644854
```

### 3. Instalasi Dependencies
```bash
npm install
```

### 4. Menjalankan Mode Development
```bash
npm run serve
# atau untuk Ionic / Vite:
# npm run dev / ionic serve
```
Buka browser dan akses alamat `http://localhost:8080` (atau sesuai port yang tampil di terminal).
